### 1. `TIMEOUT_DRIFT`: The Orderbook Absorption Trap
* **Symptom:** Positions open on an EMA crossover, quickly hit $+1.0\text{ tick}$ MFE (achieved in $59.8\%$ of losing trades), stall, and spend the remaining 80 seconds oscillating before closing at $-1\text{ to } -3\text{ ticks}$ upon timeout.
* **Causal Mechanism:** Initiation of crossover trades during localized liquidity dead-zones ($\text{ATR} < 0.0028\text{ USDT}$, $\text{CHOP} > 56.5$). The orderbook possesses passive depth that absorbs standard market orders, preventing aggressive tick progression.

### 2. `COUNTER_TREND_TRAP`: Fighting the 200 EMA Macro Impulse
* **Symptom:** High velocity stop-outs ($4.6\text{s} - 52.5\text{s}$ holds) inflicting maximum nominal loss ($-0.0020\text{ USDT}$ at $-25\%\text{ ROE}$).
* **Causal Mechanism:** Taking crossover buy signals when price is $-1.5\%\text{ to }-7.7\%$ below the 200 EMA during strong market selloffs ($\text{ADX} > 28$), or shorting parabolic pumps above the 200 EMA (e.g., Trade `#10` in Chunk 1, Trade `#5234` in Chunk 9, Trades `#3289–3297` in Chunk 34). These setups are bull/bear flag consolidations, not structural reversals.

### 3. `CHOP_WHIPSAW`: Micro-Range Boundary Traps
* **Symptom:** Rapid alternating signals (e.g., 4 consecutive losses in $<90$ minutes in Chunk 35).
* **Causal Mechanism:** In low-velocity ranges ($\text{CHOP} > 60.0$, $\text{ADX} < 18.0$), EMAs repeatedly cross near the extremes of the range. The buy signal triggers precisely at local resistance; the sell signal triggers at local support.

### 4. `VOLATILITY_WICK_OUT`: Liquidity Void Sweeps
* **Symptom:** Near-instantaneous liquidation ($3.6\text{s} - 4.6\text{s}$) where MAE exceeds $15\text{ to }34\text{ ticks}$.
* **Causal Mechanism:** Single aggressive market orders sweep thin orderbooks during anomalous volatility spikes ($\text{ATR} > 2.2\times$ the 14-period baseline), breaching the $-25\%\text{ ROE}$ threshold before micro-trends can form.

## 5. Production-Ready Algorithmic Execution Pipeline

This Python module combines the findings from all three files into an atomic, low-latency pre-trade gating and in-trade management engine.

```python
"""
TRUMP_USDT EMA_CROSSOVER Alpha Shield Execution Pipeline
Reconciled Production Architecture derived from 35-Week Forensic Datasets.
Execution Parameters: 75x Leverage, Zero Fee Tier, Target TP +2 ticks (0.002 delta).
"""

from dataclasses import dataclass
from typing import Tuple, Dict, Any
import numpy as np

@dataclass(frozen=True)
class EngineParameters:
    # Asset Microstructure Coordinates
    TICK_SIZE: float = 0.001
    TP_DELTA: float = 0.002                     # +2 ticks
    SL_ROE_LIMIT: float = 0.25                  # -25.0% ROE (~8-10 ticks at 75x)
    
    # Pre-Trade Feasibility Limits
    MIN_ATR_TICK_RATIO: float = 1.40            # 1m ATR must be >= 1.40x TP target (0.0028 USDT)
    MAX_CHOP_INDEX: float = 56.5               # CHOP > 56.5 represents dead orderbook
    MIN_ADX_TREND: float = 22.0                 # Trend momentum validation threshold
    MAX_200_EMA_DIST_PCT: float = 0.85          # Max 0.85% distance from 200 EMA to avoid extension
    MAX_VOLATILITY_EXPANSION: float = 2.20      # Current ATR / Baseline ATR ceiling
    
    # Momentum Boundary Gates
    LONG_RSI_BOUNDS: Tuple[float, float] = (46.0, 64.0)
    SHORT_RSI_BOUNDS: Tuple[float, float] = (36.0, 54.0)
    MAX_VOLUME_CLIMAX_RATIO: float = 4.0        # Reject exhaustion spikes
    MIN_VOLUME_SURGE_RATIO: float = 0.80        # Minimum participation threshold
    
    # In-Trade Dynamic Execution Controls
    BE_ACTIVATION_SECONDS: float = 15.0         # Seconds before checking +1 tick stall
    BE_MFE_TRIGGER_TICKS: float = 1.0           # Reached +1.0 tick excursion
    STALE_TRADE_TIMEOUT: float = 25.0           # Flat trade cutoff
    HARD_KILL_TIMEOUT: float = 40.0             # Absolute time kill-switch boundary


class AlphaShieldFilterPipeline:
    """
    Evaluates pre-trade market microstructure in O(1) constant time.
    Atomic validation: ALL sub-filters must return True to approve execution.
    """
    def __init__(self, params: EngineParameters = EngineParameters()):
        self.p = params

    def validate_pre_trade_setup(
        self,
        signal_type: str,
        bar: Dict[str, Any]
    ) -> Tuple[bool, str]:
        """
        bar schema: {
            'close': float, 'ema_200': float, 'atr_14': float, 'atr_baseline': float,
            'chop_14': float, 'adx_14': float, 'rsi_14': float, 'vol_surge_ratio': float
        }
        """
        close = bar['close']
        ema_200 = bar['ema_200']
        atr = bar['atr_14']
        atr_base = bar.get('atr_baseline', atr)
        chop = bar['chop_14']
        adx = bar['adx_14']
        rsi = bar['rsi_14']
        vol_ratio = bar.get('vol_surge_ratio', 1.0)

        # ---------------------------------------------------------------------
        # GATE 1: Absolute Volatility & Orderbook Traversability Gate
        # Eliminates 78-84% of TIMEOUT_DRIFT losses (Regimes 0 & 4)
        # ---------------------------------------------------------------------
        min_atr_required = self.p.TP_DELTA * self.p.MIN_ATR_TICK_RATIO
        if atr < min_atr_required:
            return False, f"REJECT_INSUFFICIENT_ATR: {atr:.6f} < Required {min_atr_required:.6f}"

        if chop >= self.p.MAX_CHOP_INDEX:
            return False, f"REJECT_CHOP_CONSOLIDATION: CHOP {chop:.1f} >= {self.p.MAX_CHOP_INDEX}"

        if atr_base > 0 and (atr / atr_base) > self.p.MAX_VOLATILITY_EXPANSION:
            return False, f"REJECT_VOLATILITY_SPIKE: ATR Expansion {atr/atr_base:.2f}x > {self.p.MAX_VOLATILITY_EXPANSION}x"

        # ---------------------------------------------------------------------
        # GATE 2: Macro 200 EMA Directional Alignment & Parabolic Extension Gate
        # Eliminates COUNTER_TREND_TRAP losses
        # ---------------------------------------------------------------------
        dist_to_ema200_pct = ((close - ema_200) / ema_200) * 100.0

        if abs(dist_to_ema200_pct) > self.p.MAX_200_EMA_DIST_PCT:
            return False, f"REJECT_PARABOLIC_EXTENSION: Dist {dist_to_ema200_pct:.2f}% exceeds limit {self.p.MAX_200_EMA_DIST_PCT}%"

        if adx >= self.p.MIN_ADX_TREND:
            if signal_type == "LONG" and dist_to_ema200_pct < -0.05:
                return False, f"REJECT_COUNTER_TREND_LONG: {dist_to_ema200_pct:.2f}% below 200 EMA with ADX {adx:.1f}"
            if signal_type == "SHORT" and dist_to_ema200_pct > 0.05:
                return False, f"REJECT_COUNTER_TREND_SHORT: +{dist_to_ema200_pct:.2f}% above 200 EMA with ADX {adx:.1f}"

        # ---------------------------------------------------------------------
        # GATE 3: Momentum Exhaustion & Volume Verification
        # Eliminates MOMENTUM_FAILURE & WICK_OUT losses
        # ---------------------------------------------------------------------
        if vol_ratio > self.p.MAX_VOLUME_CLIMAX_RATIO:
            return False, f"REJECT_CLIMAX_VOLUME: Ratio {vol_ratio:.2f}x exceeds ceiling"
        if vol_ratio < self.p.MIN_VOLUME_SURGE_RATIO:
            return False, f"REJECT_ILLIQUID_VOLUME: Ratio {vol_ratio:.2f}x below floor"

        if signal_type == "LONG":
            if not (self.p.LONG_RSI_BOUNDS[0] <= rsi <= self.p.LONG_RSI_BOUNDS[1]):
                return False, f"REJECT_RSI_OUT_OF_BOUNDS_LONG: RSI {rsi:.1f} not in {self.p.LONG_RSI_BOUNDS}"
        elif signal_type == "SHORT":
            if not (self.p.SHORT_RSI_BOUNDS[0] <= rsi <= self.p.SHORT_RSI_BOUNDS[1]):
                return False, f"REJECT_RSI_OUT_OF_BOUNDS_SHORT: RSI {rsi:.1f} not in {self.p.SHORT_RSI_BOUNDS}"
        else:
            return False, f"REJECT_INVALID_SIGNAL_TYPE: {signal_type}"

        return True, "ACCEPT_SIGNAL_PERFECT_ALIGNMENT"


class DynamicExecutionController:
    """
    Manages in-trade execution logic, dynamic breakeven stops, and hard time kill-switches.
    Replaces static 90-second timeout attrition.
    """
    def __init__(self, params: EngineParameters = EngineParameters()):
        self.p = params

    def evaluate_in_trade_state(
        self,
        elapsed_seconds: float,
        current_mfe_ticks: float,
        current_pnl_ticks: float,
        entry_price: float,
        current_price: float,
        direction: str
    ) -> Tuple[str, float]:
        """
        Returns:
            action: ['HOLD', 'MOVE_STOP_TO_BE', 'MARKET_SCRATCH', 'HARD_TIME_KILL']
            adjusted_target_price: updated stop order price coordinate
        """
        # Rule 1: Absolute Hard Time Kill-Switch
        # Any trade open beyond 40 seconds suffers negative drift expectancy
        if elapsed_seconds >= self.p.HARD_KILL_TIMEOUT:
            return "HARD_TIME_KILL", current_price

        # Rule 2: Dynamic Breakeven Guard (+1 Tick Stall Trap)
        # If position achieves +1 tick MFE within 15s but has not hit +2 ticks TP,
        # eliminate downside risk by setting stop to Entry
        if elapsed_seconds >= self.p.BE_ACTIVATION_SECONDS:
            if current_mfe_ticks >= self.p.BE_MFE_TRIGGER_TICKS and current_pnl_ticks <= 0.0:
                return "MOVE_STOP_TO_BE", entry_price

        # Rule 3: Stale Momentum Early Invalidation
        # If 25 seconds elapse with zero positive excursion, exit immediately
        if elapsed_seconds >= self.p.STALE_TRADE_TIMEOUT and current_mfe_ticks <= 0.0:
            return "MARKET_SCRATCH", current_price

        return "HOLD", 0.0
```
