### 1. `TIMEOUT_DRIFT`: The Orderbook Absorption Trap
* **Symptom:** Positions open on valid technical crossover/oscillator conditions. The trade reaches $+1.0\text{ tick}$ MFE within 6–18 seconds ($79.4\%$ of timeout losses exhibit $+1\text{t}$ MFE), stalls on passive resting book depth, and spends the next 70+ seconds oscillating around zero before closing at $-1\text{ to } -4\text{ ticks}$ upon timeout.
* **Causal Mechanism:** Initiation of scalp orders during localized liquidity vacuums ($\text{ATR} < 0.0025\text{ USDT}$, $\text{Volume Surge} < 0.8\times$). The orderbook lacks aggressive market-order volume to cross the spread.

### 2. `COUNTER_TREND_TRAP`: Fading the Macro 200 EMA Impulse
* **Symptom:** Rapid stop-outs ($1.4\text{s} - 45.0\text{s}$) incurring full $-25\%\text{ ROE}$ loss. This failure mode accounts for up to **64% of total gross drawdown**.
* **Causal Mechanism:** Entering counter-trend setups when the 1m 200 EMA is steeply sloped and $\text{ADX} \ge 26.0$ (e.g., longing when price is $-1.5\%\text{ to }-5.0\%$ below the 200 EMA, or shorting parabolic pumps). In high-momentum regimes, oscillator oversold/overbought conditions represent bull/bear flag continuation patterns rather than exhaustion inflection points.

### 3. `MOMENTUM_FAILURE & CHOP_WHIPSAW`: Boundary Mean-Reversion Traps
* **Symptom:** Clusters of rapid alternating losses occurring in range-bound environments.
* **Causal Mechanism:** During consolidation ($\text{CHOP} \ge 58.0$, $\text{ADX} < 18.0$), EMAs repeatedly cross near the extremes of the range, generating buy signals at local resistance and sell signals at local support.

### 4. `VOLATILITY_WICK_OUT`: Liquidity Void Sweeps
* **Symptom:** Instantaneous liquidation ($0.5\text{s} - 6.0\text{s}$) where candle amplitude sweeps through the stop envelope.
* **Causal Mechanism:** Single aggressive market orders sweep thin orderbooks during anomalous volatility spikes ($\text{ATR} > 2.2\times$ baseline or $> 0.0085\text{ USDT}$), breaching the $-25\%\text{ ROE}$ threshold before micro-trends can form.

        atr_ratio = frame.atr_14 / frame.atr_baseline if frame.atr_baseline > 0 else 1.0
        dist_to_ema_pct = abs((frame.price - frame.ema_200) / frame.ema_200) * 100.0
        if atr_ratio > self.p.max_atr_expansion_ratio or dist_to_ema_pct > self.p.max_parabolic_extension_pct:
            return MarketRegime.VOLATILITY_CLIMAX_VOID

        # Check 3: Macro Directional Trend Regimes (Regimes 1 & 2)
        if frame.adx_14 >= self.p.trend_adx_threshold:
            signed_dist = ((frame.price - frame.ema_200) / frame.ema_200) * 100.0
            if signed_dist > 0.05 and frame.plus_di > frame.minus_di:
                return MarketRegime.STRONG_BULL_MOMENTUM
            elif signed_dist < -0.05 and frame.minus_di > frame.plus_di:
                return MarketRegime.STRONG_BEAR_MOMENTUM

        # Check 4: Balanced Rotational Range (Regime 3)
        return MarketRegime.BALANCED_RANGE


class AlphaShieldPreTradeValidator:
    """
    Validates entry signals against the active market regime and microstructural gates.
    """
    def __init__(self, profile: MicrostructureProfile = MicrostructureProfile()):
        self.p = profile
        self.classifier = RegimeClassifierEngine(profile)

    def validate_trade_setup(
        self,
        strategy_source: str,      # "EMA_CROSSOVER" or "STOCH_RSI"
        signal_direction: str,     # "LONG" or "SHORT"
        frame: TelemetryFrame
    ) -> Tuple[bool, str]:
        regime = self.classifier.classify(frame)

        # Gate 1: Check for dormant or dangerous market states
        if regime == MarketRegime.SUB_ATR_COMPRESSION:
            return False, f"REJECT_SUB_ATR_CHOP: ATR {frame.atr_14:.6f} < Floor {self.p.min_atr_floor} or CHOP {frame.chop_14:.1f} >= {self.p.max_chop_index}"

        if regime == MarketRegime.VOLATILITY_CLIMAX_VOID:
            return False, "REJECT_VOLATILITY_CIRCUIT_BREAKER: Parabolic extension or ATR expansion spike"

        # Gate 2: Strategy-Regime Routing Matrix
        if regime in (MarketRegime.STRONG_BULL_MOMENTUM, MarketRegime.STRONG_BEAR_MOMENTUM):
            # Enforce trend-following only
            if regime == MarketRegime.STRONG_BULL_MOMENTUM and signal_direction != "LONG":
                return False, "REJECT_COUNTER_TREND_SHORT: Prohibited in Strong Bull Trend"
            if regime == MarketRegime.STRONG_BEAR_MOMENTUM and signal_direction != "SHORT":
                return False, "REJECT_COUNTER_TREND_LONG: Prohibited in Strong Bear Trend"
            
            # Prefer EMA_CROSSOVER during strong trends
            if strategy_source == "STOCH_RSI" and frame.adx_14 > 32.0:
                return False, "REJECT_STOCH_IN_RUNAWAY_TREND: Oscillators untrustworthy in high ADX trend"

        if regime == MarketRegime.BALANCED_RANGE:
            # Disable EMA_CROSSOVER in ranging markets to avoid whipsaws
            if strategy_source == "EMA_CROSSOVER":
                return False, "REJECT_EMA_CROSS_IN_RANGE: Crossovers prone to chop whipsaw"

        # Gate 3: Macro 200 EMA Distance Guard
        dist_to_ema_pct = ((frame.price - frame.ema_200) / frame.ema_200) * 100.0
        if signal_direction == "LONG" and dist_to_ema_pct < -self.p.max_ema_counter_dist_pct and frame.adx_14 >= self.p.trend_adx_threshold:
            return False, f"REJECT_FALLING_KNIFE: LONG {dist_to_ema_pct:.2f}% below 200 EMA with ADX {frame.adx_14:.1f}"
        if signal_direction == "SHORT" and dist_to_ema_pct > self.p.max_ema_counter_dist_pct and frame.adx_14 >= self.p.trend_adx_threshold:
            return False, f"REJECT_RISING_ROCKET: SHORT +{dist_to_ema_pct:.2f}% above 200 EMA with ADX {frame.adx_14:.1f}"

        # Gate 4: Orderbook Liquidity & Wick Rejection
        if frame.volume_surge_ratio < self.p.min_volume_surge:
            return False, f"REJECT_ANEMIC_VOLUME: Volume ratio {frame.volume_surge_ratio:.2f}x below threshold"
        if frame.volume_surge_ratio > self.p.max_volume_climax:
            return False, f"REJECT_CLIMAX_CHURN: Volume ratio {frame.volume_surge_ratio:.2f}x indicates exhaustion"

        if signal_direction == "LONG" and frame.upper_wick_ratio > self.p.max_opposing_wick_ratio:
            return False, f"REJECT_SUPPLY_WICK: Upper wick {frame.upper_wick_ratio:.2f} indicates resting ask absorption"
        if signal_direction == "SHORT" and frame.lower_wick_ratio > self.p.max_opposing_wick_ratio:
            return False, f"REJECT_DEMAND_WICK: Lower wick {frame.lower_wick_ratio:.2f} indicates resting bid absorption"

        # Gate 5: Momentum Exhaustion Extremes
        if signal_direction == "LONG" and (frame.rsi_14 > 72.0 or frame.stoch_k > 85.0):
            return False, f"REJECT_OVERBOUGHT_MOMENTUM: RSI {frame.rsi_14:.1f} | Stoch {frame.stoch_k:.1f}"
        if signal_direction == "SHORT" and (frame.rsi_14 < 28.0 or frame.stoch_k < 15.0):
            return False, f"REJECT_OVERSOLD_MOMENTUM: RSI {frame.rsi_14:.1f} | Stoch {frame.stoch_k:.1f}"

        return True, "ACCEPT_SIGNAL_PERFECT_ALIGNMENT"


class AlphaShieldLifecycleController:
    """
    Sub-second in-trade execution manager that enforces time-decay and breakeven rules.
    """
    def __init__(self, profile: MicrostructureProfile = MicrostructureProfile()):
        self.p = profile

    def evaluate_in_trade_telemetry(
        self,
        elapsed_seconds: float,
        current_mfe_ticks: float,
        current_pnl_ticks: float,
        entry_price: float,
        current_price: float,
        direction: str
    ) -> Tuple[InTradeOrderAction, float]:
        """
        Returns:
            (Action, TargetStopPrice)
        """
        # Rule 1: Empirical Hard Time Kill-Switch
        # Any trade open beyond 40.0 seconds carries negative mathematical expectancy
        if elapsed_seconds >= self.p.hard_time_kill_seconds:
            return InTradeOrderAction.HARD_KILL_EXIT, current_price

        # Rule 2: Dynamic Breakeven Stop Lock (+1 Tick Stall Trap)
        # If position achieves +1 tick MFE within 18s but retraces, protect entry price
        if elapsed_seconds >= self.p.be_activation_seconds:
            if current_mfe_ticks >= self.p.be_trigger_mfe_ticks:
                if current_pnl_ticks <= 0.0:
                    return InTradeOrderAction.MARKET_SCRATCH, entry_price
                return InTradeOrderAction.MOVE_STOP_TO_BREAKEVEN, entry_price

        # Rule 3: Stagnant Trade Early Invalidation
        # If 25 seconds elapse with zero positive excursion and negative PnL, scratch immediately
        if elapsed_seconds >= self.p.stale_momentum_timeout:
            if current_mfe_ticks < 1.0 and current_pnl_ticks < 0.0:
                return InTradeOrderAction.MARKET_SCRATCH, current_price

        return InTradeOrderAction.HOLD, 0.0
