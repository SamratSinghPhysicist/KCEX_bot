### 1.1 `TIMEOUT_DRIFT` (82.4% of Losses)
* **Mechanics:** The model enters on a Stoch RSI crossover (`%K < 20` for Long, `%K > 80` for Short). At $T = 90.0\text{s} - 95.0\text{s}$, the safety exit triggers a market close at $-0.0002$ to $-0.0014$ USDT ($-2.5\%$ to $-18\%$ ROE).
* **Forensic Evidence:**
  * *Chunk 1, Trade #3:* Entered Long at 4.807000. Reached MFE of +2.0 ticks (partial fill/spread wall), stalled for 90.1s, exited at 4.803000 ($-6.24\%$ ROE). Post-exit: Reached TP? `NO`.
  * *Chunk 8, Trade #9174:* Entered Long at 3.498000. ADX 14.48, CHOP 54.8. Stalled for 91.1s, exited at 3.495000 ($-6.43\%$ ROE).
  * *Chunk 14, Trade #17528:* Entered Short at 2.893000. Stalled for 90.9s, exited at 2.896000 ($-7.78\%$ ROE).
* **Causal Root:** Entering during **volume and volatility exhaustion**. When the 1m candle's Volume Surge Ratio is $< 0.8\times$ and ATR is below its 50-period moving average, market microstructure lacks the aggressive market-order pressure necessary to clear 2 full ticks of orderbook depth within 90 seconds.

### 1.2 `COUNTER_TREND_TRAP` (11.2% of Losses — 64% of Capital Drawdown)
* **Mechanics:** Stoch RSI indicates an "overbought" or "oversold" mean-reversion opportunity while the macro market (200 EMA) is in an aggressive directional trend accompanied by an ADX $> 30.0$. The bot steps directly in front of a multi-standard-deviation trend impulse, hitting the $-25\%$ ROE Stop Loss in $1.4\text{s} - 45.0\text{s}$.
* **Forensic Evidence:**
  * *Chunk 4, Trade #3607:* LONG entered at 4.960000 while price was **$-3.59\%$ below the 200 EMA** with **ADX at 55.96**. Smashed SL in **2.6 seconds** ($-15.12\%$ ROE).
  * *Chunk 8, Trade #9151:* SHORT entered at 3.513000 while price was **$+1.99\%$ above the 200 EMA** with **ADX at 38.74**. Stopped out in 59.3s ($-21.35\%$ ROE).
  * *Chunk 13, Trade #16218:* SHORT entered at 3.171000 while price was **$+2.35\%$ above 200 EMA**, ADX 47.5, RSI 90.4. Stopped out in **17.2s** ($-23.6\%$ ROE).
  * *Chunk 35, Trade #45986:* LONG entered at 2.501000 while price was **$-4.91\%$ below 200 EMA**, ADX 50.14. Stopped out in **1.4 seconds** ($-30.0\%$ ROE).
* **Causal Root:** Complete absence of a macro trend-invalidation gate. Stoch RSI is an oscillator; in parabolic regimes, oscillators remain pinned in extreme overbought/oversold territory while price continues to expand exponentially.

### 1.3 `CHOP_WHIPSAW` (4.8% of Losses)

## 4. Production-Ready Algorithmic Filters (Python)

Below is the complete, drop-in Python implementation for the bot's `FilterPipeline`. It incorporates the three algorithmic filters derived from the autopsy data:

```python
"""
TRUMP_USDT STOCH_RSI Quantitative Filter Pipeline
Backtest Run ID: backtest_TRUMP_USDT_20260905_113335
Designed for 1m OHLCV Execution with 75x Leverage
"""

import numpy as np
import pandas as pd

class InstitutionalScalpFilterPipeline:
    def __init__(self):
        # Hyperparameters derived from 36-chunk autopsy synthesis
        self.MAX_COUNTER_TREND_EMA_DIST_PCT = 0.0040  # 0.40% max distance against 200 EMA
        self.TREND_BLOWOUT_ADX_THRESHOLD = 32.0       # ADX ceiling for counter-trend trades
        self.MIN_VOLUME_SURGE_RATIO = 1.10           # Minimum 1.1x volume surge over 20-period SMA
        self.MAX_CHOPPINESS_INDEX = 61.8             # Standard Fibonacci chop ceiling (Severe consolidation)
        self.MIN_CHOPPINESS_INDEX = 35.0             # Parabolic trend threshold (Exhaustion wick trap)
        self.MIN_ATR_PRICE_RATIO = 0.0008            # Minimum ATR / Price ratio to ensure 2-tick viability
        self.OPTIMAL_TIME_KILL_SECONDS = 45.0        # Reduced from 90.0s to eliminate TIMEOUT_DRIFT

    def filter_trend_regime(self, signal: str, current_price: float, ema_200: float, adx: float) -> bool:
        """
        RULE 1: Macro-Trend & Exhaustion Filter (Eliminates COUNTER_TREND_TRAP)
        Blocks counter-trend entries when the macro trend has strong momentum.
        """
        dist_to_ema = (current_price - ema_200) / ema_200

        if signal == "LONG":
            # Counter-trend: Price is below 200 EMA in a trending market
            if dist_to_ema < -self.MAX_COUNTER_TREND_EMA_DIST_PCT and adx > self.TREND_BLOWOUT_ADX_THRESHOLD:
                return False  # REJECT: Severe downtrend blowout (e.g. Chunk 4 #3607, Chunk 35 #45986)
            if dist_to_ema < -0.015:  # Hard floor: Never long when >1.5% below 200 EMA
                return False

        elif signal == "SHORT":
            # Counter-trend: Price is above 200 EMA in a trending market
            if dist_to_ema > self.MAX_COUNTER_TREND_EMA_DIST_PCT and adx > self.TREND_BLOWOUT_ADX_THRESHOLD:
                return False  # REJECT: Parabolic expansion squeeze (e.g. Chunk 8 #9151, Chunk 13 #16218)
            if dist_to_ema > 0.015:   # Hard ceiling: Never short when >1.5% above 200 EMA
                return False

        return True

    def filter_microstructure_volatility(self, atr: float, current_price: float, 
                                        volume_current: float, volume_sma20: float) -> bool:
        """
        RULE 2: Microstructure Volatility & Orderbook Velocity Filter (Eliminates TIMEOUT_DRIFT)
        Ensures candle volatility and orderbook volume support a 2-tick move within 45 seconds.
        """
        # Volatility viability: Check if 1-period ATR covers at least 2 full ticks plus spread
        atr_price_ratio = atr / current_price
        if atr_price_ratio < self.MIN_ATR_PRICE_RATIO:
            return False  # REJECT: Sub-tick deadlock; orderbook too stagnant for fast scalping

        # Volume velocity: Confirm aggressive liquidity presence
        volume_surge_ratio = volume_current / volume_sma20 if volume_sma20 > 0 else 0.0
        if volume_surge_ratio < self.MIN_VOLUME_SURGE_RATIO:
            return False  # REJECT: Low participation setup; high probability of 45s timeout

        return True

    def filter_chop_regime(self, chop_index: float, adx: float, rsi: float, signal: str) -> bool:
        """
        RULE 3: Dynamic Choppiness & Exhaustion Guard (Eliminates CHOP_WHIPSAW)
        Rejects entries during dead consolidation and extreme oscillator divergence.
        """
        # Rejection zone 1: Severe consolidation chop (noise whipsaw)
        if chop_index > self.MAX_CHOPPINESS_INDEX and adx < 18.0:
            return False

        # Rejection zone 2: Parabolic blow-off (where oscillators give fake mean-reversion signals)
        if chop_index < self.MIN_CHOPPINESS_INDEX and (rsi > 78.0 or rsi < 22.0):
            return False

        # Rejection zone 3: Extreme RSI saturation
        if signal == "LONG" and rsi < 25.0 and adx > 35.0:
            return False  # Falling knife
        if signal == "SHORT" and rsi > 75.0 and adx > 35.0:
            return False  # Rocket launch

        return True

    def evaluate_execution_gates(self, signal: str, current_price: float, ema_200: float,
                                  adx: float, atr: float, chop_index: float, rsi: float,
                                  volume_current: float, volume_sma20: float) -> bool:
        """
        Master Pipeline Evaluation Method: Evaluates whether a candidate trade passes all filters.
        """
        if not self.filter_trend_regime(signal, current_price, ema_200, adx):
            return False
        
        if not self.filter_microstructure_volatility(atr, current_price, volume_current, volume_sma20):
            return False
            
        if not self.filter_chop_regime(chop_index, adx, rsi, signal):
            return False

        return True  # Setup approved for 75x execution
```
