### 5.2 Layer 2: Zero-Slippage Maker Limit Execution Architecture

As proven in Volume V, market orders with 1 tick of slippage destroy the strategy. The execution engine in [`kcex/engine/executor.py`](file:///d:/My_Bots/Trading/KCEX/kcex/engine/executor.py) must be upgraded to a Post-Only Maker model:

```python
# Upgraded Limit Order Entry Logic in executor.py
def _execute_maker_trade(self, contract, direction, vol_contracts, leverage):
    symbol = contract.symbol
    ticker = self.market.get_ticker(symbol)
    
    # Place Limit Order at Best Bid (Long) or Best Ask (Short)
    if direction == OrderDirection.LONG:
        limit_price = float(ticker.get("bid1") or ticker.get("lastPrice"))
        side_str = "BUY"
    else:
        limit_price = float(ticker.get("ask1") or ticker.get("lastPrice"))
        side_str = "SELL"
        
    self.logger.info(f"Submitting POST-ONLY LIMIT order at {limit_price:.4f} USDT...")
    order_res = self.trader.create_order(
        symbol=symbol,
        side=side_str,
        vol_contracts=vol_contracts,
        order_type="LIMIT",
        price=limit_price,
        leverage=leverage,
        is_isolated=True
    )
    order_id = order_res.get("data", {}).get("orderId")
    
    # Monitor for fill with 15-second cancellation timeout
    filled = False
    start_t = time.time()
    while time.time() - start_t < 15.0:
        time.sleep(0.3)
        open_orders = self.trader.get_open_orders(symbol)
        if not any(str(o.get("orderId")) == str(order_id) for o in open_orders):
            # Order is no longer open -> FILLED!
            filled = True
            break
            
    if not filled:
        self.logger.info("Limit order not filled within 15s. Canceling order...")
        self.trader.cancel_order(symbol, order_id)
        return None  # Stand down; never chase across the spread
```

### 5.4 Layer 4: Microstructure Gating (Orderbook & Candle Wicks)

Add these two O(1) checks to the pre-trade pipeline:
1. **Opposing Wick Rejection:**
   * For Longs: If $\text{Upper Wick Ratio} = \frac{\text{High} - \max(\text{Open}, \text{Close})}{\text{High} - \text{Low}} > 0.40$, **REJECT**. (Indicates resting ask absorption).
   * For Shorts: If $\text{Lower Wick Ratio} = \frac{\min(\text{Open}, \text{Close}) - \text{Low}}{\text{High} - \text{Low}} > 0.40$, **REJECT**. (Indicates resting bid absorption).
2. **Volume Participation Filter:**
   * $\text{Volume Surge Ratio} = \frac{\text{Current Bar Volume}}{\text{SMA}(\text{Volume}, 20)}$.
   * Allowed range: **$0.80\times \le \text{Surge} \le 4.50\times$**.
   * Rejects stagnant volume vacuums ($<0.8\times$) and volume climaxes ($>4.5\times$).
