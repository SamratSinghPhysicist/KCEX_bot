## 1. Deep Forensic Loss Autopsy Across All 35 Chunks

Analysis of over **2,600 losing trades** across the 35 dossiers reveals four distinct failure fingerprints:

```
                      DISTRIBUTION OF FAILURE MODES
  +-------------------------------------------------------------------+
  | █████████████████████████████████████████░░░░░░░░░░░░░░░░░░░░░░░░ |
  | Timeout Drift (68.4%) | Counter-Trend (16.2%) | Chop (11.8%) | Wicks (3.6%)
  +-------------------------------------------------------------------+
```

### 1. "Timeout Drift" (68.4% of Total Losses)
* **The Microstructure Failure:** The strategy relies on aggressive orderbook momentum to take price +2 ticks through the spread immediately after the EMA crossover. In 68.4% of losses, the orderbook thins out immediately following the signal. Price stalls at an MFE (Max Favorable Excursion) of `+0.00` to `+1.00 ticks`.
* **Duration Disparity:**
  * **Winning Trades:** Median holding duration of **`12.4 seconds`** (over 78% hit TP in under 30 seconds).
  * **Losing Trades:** Median holding duration of **`482.0 seconds`** (ranging from 120s up to 7,929s).
* **The Fatal Trap:** When a scalp fails to fill within 45 seconds, the probability of reaching the +2 tick TP drops from **85.3% to 8.1%**. Positions left open slowly drift into adverse inventory imbalances, eventually triggering the -25% ROE stop loss.

### 2. "Counter-Trend Trap" (16.2% of Total Losses)
* **The Microstructure Failure:** Occurs when the 1m fast EMA crosses the slow EMA against the macro trend (the 200 EMA) while trend strength is high ($\text{ADX} \ge 25.0$).
* **Empirical Forensic Signatures:**
  * Chunk 1 `#8`: LONG entered at $4.782 while price was **-1.77% below the 200 EMA** with **ADX at 42.1**. Stopped out in 21 seconds.
  * Chunk 9 `#4559`: LONG entered at $3.217 while price was **-3.28% below the 200 EMA** with **ADX at 27.3**. Stopped out in 65 seconds.
  * Chunk 12 `#6383`, `#6400`, `#6407`, `#6414`: Consecutive LONG signals triggered during an aggressive breakdown channel below the 200 EMA, each stopping out within 30–50 seconds.
* **The Fatal Trap:** Fast EMA crossovers in strong macro trends are almost exclusively **bear/bull flag consolidations** or liquidity sweeps, not reversals.

### 3. "Chop Whipsaw" (11.8% of Total Losses)
* **The Microstructure Failure:** In low-volatility consolidation ranges ($\text{CHOP Index} \ge 61.8$ and $\text{ADX} < 18.0$), the fast and slow EMAs repeatedly oscillate around each other.
* **Empirical Forensic Signatures:**
  * Chunk 2 `#359`: SHORT at $5.464 with **ADX 7.8** and **CHOP 61.8**. Stopped in 23s.
  * Chunk 10 `#5173`: LONG with **ADX 15.2**, Volume Surge **8.98x**, but **CHOP 44.0** with extreme adverse orderbook absorption. Stopped in 18s.
  * Chunk 35 `#17530`, `#17531`, `#17539`, `#17540`: Four consecutive whipsaw losses in under 90 minutes during an intraday compression cluster.
* **The Fatal Trap:** EMA crossovers lag price action. In tight trading ranges, the crossover occurs near the boundary of the range, causing entries directly into range support/resistance.

### 4. "Volatility Wick-Out" (3.6% of Total Losses)
* **The Microstructure Failure:** Large limit order liquidations or aggressive market orders create a instantaneous spread widening.
* **Empirical Forensic Signatures:**
  * Chunk 2 `#380`: Stopped in **4.6 seconds** with MAE of +34 ticks.
  * Chunk 12 `#6354`: Stopped in **3.6 seconds** with MAE of +26 ticks.
  * Chunk 35 `#17548`: Stopped in **3.6 seconds** with MAE of +5 ticks.
* **The Fatal Trap:** When ATR spikes to more than 2.5× the 14-period baseline, 1-minute candle spreads widen beyond the 2-tick target, causing slippage and instant stop-outs.

## 4. Production-Ready Python Filters (`FilterPipeline`)

These three production-ready Python filter classes are designed to plug directly into the algorithmic execution engine. They operate on a vector/bar state dictionary and evaluate to `True` (allow trade) or `False` (invalidate/block trade).

```python
"""
Institutional Microstructure Filter Pipeline for TRUMP_USDT 1m Scalping Engine
Hyperparameters: 75x Leverage | TP: +2 ticks | SL: -25% ROE
"""

import numpy as np

class MacroRegimeTrendFilter:
    """
    Filter 1: Macro Regime & Distance Gate
    Eliminates COUNTER_TREND_TRAP by enforcing directional alignment with the 200 EMA
    whenever the market displays directional momentum (ADX >= 22.0). Also blocks trades
    when the asset is overextended (>0.80% from 200 EMA), which signals exhaustion.
    """
    def __init__(self, adx_trend_threshold: float = 22.0, max_ema_dist_pct: float = 0.80):
        self.adx_trend_threshold = adx_trend_threshold
        self.max_ema_dist_pct = max_ema_dist_pct

    def validate(self, signal_direction: str, current_price: float, 
                 ema_200: float, adx: float) -> tuple[bool, str]:
        dist_pct = ((current_price - ema_200) / ema_200) * 100.0
        
        # 1. Overextension Exhaustion Gate: Block entries if extended from the 200 EMA
        if abs(dist_pct) > self.max_ema_dist_pct:
            return False, f"REJECT_OVEREXTENSION: Distance to 200 EMA ({dist_pct:.2f}%) exceeds limit ({self.max_ema_dist_pct}%)"
            
        # 2. Macro Alignment Gate: When ADX shows an active trend, enforce 200 EMA co-directionality
        if adx >= self.adx_trend_threshold:
            if signal_direction == "LONG" and dist_pct < -0.05:
                return False, f"REJECT_COUNTER_TREND: LONG signal blocked below 200 EMA ({dist_pct:.2f}%) with ADX {adx:.1f}"
            if signal_direction == "SHORT" and dist_pct > 0.05:
                return False, f"REJECT_COUNTER_TREND: SHORT signal blocked above 200 EMA ({dist_pct:.2f}%) with ADX {adx:.1f}"
                
        return True, "ACCEPT_MACRO_VALID"


class VolatilityChopMomentumFilter:
    """
    Filter 2: Microstructure Chop & Volatility Exhaustion Gate
    Eliminates CHOP_WHIPSAW and MOMENTUM_FAILURE by:
    1. Blocking trades during consolidation (CHOP Index >= 60.0 AND ADX < 20.0).
    2. Preventing long entries into overbought exhaustion (Stoch %K > 85.0 or RSI > 68.0).
    3. Preventing short entries into oversold exhaustion (Stoch %K < 15.0 or RSI < 32.0).
    4. Rejecting trades during anomalous volatility spikes (ATR Ratio > 2.2x).
    """
    def __init__(self, chop_limit: float = 60.0, adx_min: float = 18.0, 
                 stoch_upper: float = 85.0, stoch_lower: float = 15.0,
                 max_atr_ratio: float = 2.2):
        self.chop_limit = chop_limit
        self.adx_min = adx_min
        self.stoch_upper = stoch_upper
        self.stoch_lower = stoch_lower
        self.max_atr_ratio = max_atr_ratio

    def validate(self, signal_direction: str, chop_index: float, adx: float, 
                 stoch_k: float, rsi: float, current_atr: float, 
                 baseline_atr: float) -> tuple[bool, str]:
        # 1. Chop / Consolidation Regime Gate
        if chop_index >= self.chop_limit and adx < self.adx_min:
            return False, f"REJECT_CHOP: Range compression (CHOP: {chop_index:.1f} >= {self.chop_limit}, ADX: {adx:.1f} < {self.adx_min})"

        # 2. Momentum Exhaustion Extremes
        if signal_direction == "LONG":
            if stoch_k > self.stoch_upper or rsi > 68.0:
                return False, f"REJECT_EXHAUSTION_LONG: Stoch %K ({stoch_k:.1f}) or RSI ({rsi:.1f}) overbought"
        elif signal_direction == "SHORT":
            if stoch_k < self.stoch_lower or rsi < 32.0:
                return False, f"REJECT_EXHAUSTION_SHORT: Stoch %K ({stoch_k:.1f}) or RSI ({rsi:.1f}) oversold"

        # 3. Volatility Outlier Wick Gate
        if baseline_atr > 0 and (current_atr / baseline_atr) > self.max_atr_ratio:
            return False, f"REJECT_VOLATILITY_WICK: ATR expansion ({current_atr / baseline_atr:.2f}x) risks immediate spread stop-out"

        return True, "ACCEPT_MICROSTRUCTURE_VALID"


class ExecutionTimeoutManager:
    """
    Filter 3: Execution Time-Decay & Breakeven Kill-Switch
    Operates during the active trade lifecycle:
    1. Hard Kill-Switch: If position hold duration >= 45 seconds, execute MARKET_SCRATCH.
    2. Dynamic BE Stop: If position reaches +1 tick MFE within 15 seconds, trail SL to Entry.
    """
    def __init__(self, hard_timeout_seconds: float = 45.0, be_trigger_seconds: float = 15.0):
        self.hard_timeout = hard_timeout_seconds
        self.be_trigger = be_trigger_seconds

    def evaluate_active_trade(self, elapsed_seconds: float, current_mfe_ticks: float, 
                              entry_price: float, current_price: float, 
                              direction: str) -> tuple[str, float]:
        """
        Returns:
            action: 'HOLD', 'SCRATCH_NOW', or 'UPDATE_STOP_BE'
            target_price: Updated price coordinate if modifying order
        """
        # Rule A: Hard Time-Stop Trigger
        if elapsed_seconds >= self.hard_timeout:
            return "SCRATCH_NOW", current_price

        # Rule B: +1 Tick Stagnation -> Breakeven Guard
        if elapsed_seconds >= self.be_trigger and current_mfe_ticks >= 1.0:
            return "UPDATE_STOP_BE", entry_price

        return "HOLD", 0.0
```
